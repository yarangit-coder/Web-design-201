# Web-design-201
#### การออกแบบเว็บไซต์ แนวคิด วิเคราะห์ ออกแบบ พัฒนา ทดสอบและนำไปใช้จริง

## เนื้อหารายละเอียด
1. ความรู้เกี่ยวกับเทคโนโลยีเว็บ
2. เครื่องมือการพัฒนาเว็บไซต์
3. หลักการและแนวคิดของเทคโนโลยีเว็บ
4. องค์ประกอบของเว็บไซต์
5. ประเภทของเว็บไซต์
6. ภาษาเว็บไซต์ HTML
7. การจัดรูปแบบเว็บไซต์ CSS
8. การโต้ตอบกับเว็บไซต์ Javascript
9. พื้นที่จัดเก็บ Web Server, Hosting
10. การเผยแพร่เว็บไซต์
11. การบริหารจัดการเว็บไซต์
12. โครงงานการพัฒนาเว็บไซต์ทางธุรกิจ
